Same data as a Phrase project

  • One TWB task per Wordbee job: TR → Translation, RV → Revision.
  • Word counts come from Wordbee (per language, shared between parts by segment count). The project word count is the first target language's total, as with Phrase.
  • Deadlines follow the Phrase self-service rule: Translation due at 55% of the time left, Revision at 95%. TWB sends them to Wordbee (jobs/{id}/properties).
  • Revisions for French wait until all three Translation parts are complete, as for split Phrase jobs.
  • Tasks are published and tracked for the project creator, entitlement is used, and the source file is copied to each task.

Gap GAP

The dashed buttons don't exist yet. Without them, TWB catches up with Wordbee through webhooks and a poll every 10 minutes, but an admin can't trigger it.

To confirm on Wordbee

That one Wordbee request creates both the Translation and the Revision job for each part, and that the parts come back in order. The docs don't say.
