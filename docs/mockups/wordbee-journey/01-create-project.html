⑂Translation system

Phrase is the standard workflow. Katong (sandbox, test content only) machine translates the file, then TWB linguists review it in the Katong editor. Wordbee creates Translation and Revision jobs in Wordbee Translator, split into parts of about 2000 words, and TWB linguists work on them in the Wordbee editor.

Who sees the switch

Only site admins, and only when [wordbee] enabled is set in conf.ini. Org admins see the form without this card and always use Phrase.

When Wordbee is selected

  • The language lists only show languages Wordbee has (from settings/languages/codes).
  • The allowed file types come from Wordbee (settings/documentformats).
  • The template buttons are switched off.
  • On submit, the page checks the file type and that no two targets map to the same Wordbee language.

On "Create Project"

  1. TWB saves the project and the file, as for Phrase.
  2. API1 POST projects creates a Standard project, reference twb-project-61237, with Translation and Revision steps.
  3. API2 sets the workflow template, uploads the file and starts the import.
  4. TWB writes the same rows as a Phrase project, plus WordbeeProjects.
