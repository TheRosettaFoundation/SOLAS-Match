What's happening now

  1. Wordbee is importing cholera-leaflet.docx: splitting it into segments, pre-translating from memory and counting words. This runs in the background (an async "trm" request).
  2. TWB waits up to 20 seconds while creating the project. If Wordbee hasn't finished by then, Wordbee calls TWB back at /wordbee_hook?type=trm when it's done; the every-minute cron job is the fallback.
  3. Then, for each language, TWB reads the word count and asks Wordbee for jobs (workflows/jobs/new), split if over 2000 words. That's another background request.
