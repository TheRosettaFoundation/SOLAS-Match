When Amina clicks complete in Wordbee

  1. Wordbee sets job 301 to Completed and calls the TWB webhook (/wordbee_hook, checked with the shared secret).
  2. TWB re-reads the project's jobs. For job 301 it does what it does for a completed Phrase job: status Complete, completion date, and the usual task-completed notifications.
  3. It saves Wordbee's word-count figures.
  4. The French Revisions stay Waiting until parts 1.2 and 1.3 are also complete. Swahili shows the other case: its Translation is done, so its Revision is now claimable.
If the webhook is missed, the 10-minute poll makes the same changes.

Other changes TWB picks up from Wordbee

  • Job reopened → task back to In progress.
  • Job cancelled → task cancelled in TWB.
  • Linguist removed from the job in Wordbee → task unclaimed in TWB.

Gaps on this page

  • Per-part download isn't possible; the file arrives once the whole language is done.
  • The Wordbee figures are saved but no TWB page shows them.
  • Wordbee only allows status-change webhooks to be set up in its admin screens, so they have to be configured by hand (see docs/wordbee/README.md).
